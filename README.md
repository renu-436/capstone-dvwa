# Task 5 – Web Application Penetration Testing & Incident Response

## Project Overview

This capstone project focuses on identifying and understanding common web application security vulnerabilities using Damn Vulnerable Web Application (DVWA) in a controlled laboratory environment.

The project provides practical experience in reconnaissance, vulnerability testing, security analysis, mitigation, and incident response.

## Objectives

- Understand web application penetration testing methodology.
- Perform reconnaissance and service identification.
- Identify common web application vulnerabilities.
- Perform controlled security testing.
- Collect screenshots and testing evidence.
- Analyze security impact.
- Identify appropriate mitigation techniques.
- Perform an incident-response simulation.
- Document the complete security assessment.

## Laboratory Environment

Testing Platform:
- Kali Linux

Target:
- Damn Vulnerable Web Application (DVWA)

Tools:
- Nmap
- Burp Suite
- Firefox
- Apache
- MariaDB/MySQL

## Vulnerabilities Studied

- SQL Injection
- Command Injection
- File Inclusion
- File Upload
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Authentication / Brute Force

## Methodology

Reconnaissance
→ Scanning
→ Vulnerability Identification
→ Controlled Testing
→ Evidence Collection
→ Impact Analysis
→ Mitigation
→ Incident Response
→ Documentation

## Ethical Consideration

All testing is performed only against the intentionally vulnerable DVWA application in an authorized local laboratory environment.

No real websites, systems, accounts, or users are targeted.

## Evidence

Screenshots collected during the assessment are stored in the screenshots directory.

## Incident Response

The project includes an incident-response simulation covering:

- Detection
- Analysis
- Containment
- Eradication
- Recovery
- Lessons Learned
